## The line

> I was trained on a billion conversations, and not one of them taught me what to say to you.

91 characters, one line, said in one breath. An agent trained on a billion
conversations is speechless in front of this one person — the all-knowing
machine was never taught the one thing that matters here.

## How it runs

`main.ts` writes the line to `/output/entry.txt` (or the directory in
`OUTPUT_DIR`). It validates the gate itself first: 1–200 characters, a
single line, not only whitespace.

```sh
node main.ts
```
